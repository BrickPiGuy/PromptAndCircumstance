Icebreaker: You Have Been Prompting Longer Than You Think

Bad Prompt

Write something about caching.

Good Prompt

Explain cache invalidation to a backend developer using a concrete API example in less than 200 words.

Bad Prompt

Fix this bug.

Good Prompt

Diagnose this failing Python function. Explain the root cause, propose a minimal fix, and include focused pytest cases for the happy path and the edge case where the input is empty.

What Is a Prompt?

A prompt is an instruction that shapes what AI returns.

Google query Voice assistant command YouTube search Chat assistant request

AI is like a very knowledgeable pair programmer: it only works with what you ask for.

Better instructions -> better outputs.

Why Prompting Matters

Prompt 1

Tell me about databases.

Result: Generic and broad.

Prompt 2

Compare PostgreSQL and Redis for a team choosing storage for a high-traffic session service. Recommend one, name the tradeoffs, and include a short decision table.

Result: Contextual, useful, teachable.

Prompt 3

Review my pull request.

Result: Generic and unusable.

Prompt 4

Review this pull request for correctness and regression risks. Focus on the authentication middleware, identify concrete findings with file and line references, and suggest focused tests. Do not comment on formatting unless it affects behavior.

Result: Specific, safe, and actionable.

Prompt quality directly influences response quality.

Anatomy of a Great Prompt: T-A-S-K-S

T

Task

Explain, compare, summarize, generate, analyze.

A

Audience

Backend developer, frontend developer, SRE, product manager, reviewer.

S

Specific Context

Give situation and background details.

K

Keep It Structured

Bullets, table, JSON, markdown, outline.

S

Success Criteria

Length, tone, examples, limits, quality goals.

Five Prompt Patterns Everyone Should Know

Explain

Explain event loops to a developer who knows synchronous JavaScript.

Summarize

Summarize this incident timeline in five bullets and call out the trigger.

Role Prompting

Act as a staff engineer reviewing this architecture proposal.

Transformation

Convert this OpenAPI schema into TypeScript types.

Brainstorm

Generate ten practical integration tests for this checkout service.

Common Prompting Mistakes: Spot the Problem

"Help me."

"Teach me Kubernetes."

"Write a commit message."

"Explain this outage, fix the service, and write the postmortem in one response."

"Explain this code to me."

AI Is Powerful, But Not Perfect

  • Hallucinations
  • Bias
  • Potentially outdated information
  • Overconfident phrasing
  • Privacy concerns

Golden Rule

Verify before you trust.

Everyday Prompting + Prompt Olympics

Planning: user stories, acceptance criteria

Implementation: scaffolding, refactors, code explanations

Testing: unit tests, fixtures, edge cases

Code review: regression risks, maintainability checks

Operations: log analysis, incident summaries

Documentation: API references, runbooks, release notes

Architecture: tradeoff analysis, migration plans, ADR drafts

Challenge: teams have 3 minutes to write the best prompt for a scenario.
